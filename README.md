# Gouri Nandana - Security Engineer Portfolio 🛡️
A modern, responsive, and cyber-themed portfolio website built to showcase my journey as a **Security Engineer** and **Cloud Security Consultant**. This project highlights my skills, experience, certifications, and projects in the cybersecurity domain.

https://portfolio-new-gouri-nandana.vercel.app/

## 🚀 Features
-   **Cyber Aesthetic**: deeply integrated dark mode with neon cyan/green accents, glassmorphism, and "hacker-style" visuals.
-   **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
-   **Interactive Elements**: Smooth hover effects, glow animations, and polished UI components.
-   **Contact Form**: Functional contact form powered by **EmailJS** for direct messaging.
-   **Resume Download**: One-click access to my professional resume.
-   **Project Showcase**: Detailed cards for key projects with tech stacks and descriptions.
## 🛠️ Tech Stack
-   **Frontend**: [React.js](https://reactjs.org/) (Vite)
-   **Styling**: Vanilla CSS3 (Variables, Flexbox, Grid)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **Animations**: CSS Transitions & [Framer Motion](https://www.framer.com/motion/)
-   **Email Service**: [EmailJS](https://www.emailjs.com/)
## 📂 Project Structure
```
src/

```
## 🔧 Getting Started
1.  **Clone the repository**
    ```bash
    git clone https://github.com/gouriiinandana/Gouri-Nandana-Portfolio.git
    cd Gouri-Nandana-Portfolio
    ```
2.  **Install Dependencies**
    ```bash
    npm install
    ```
3.  **Run Locally**
    ```bash
    npm run dev
    ```
4.  **Build for Production**
    ```bash
    npm run build
    ```
